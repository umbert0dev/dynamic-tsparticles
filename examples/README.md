## Vue 3 (`vue3-minimal`)

Uses **`dynamic-tsparticles-vue3`** via `file:../../packages/vue3`.

From repo root:

```bash
npm run example:vue3
```

Or manually:

```bash
cd vue3-minimal
npm install
npm run dev
```

## React (`react-minimal`)

Uses **`dynamic-tsparticles-react`** via `file:../../packages/react`.

From repo root:

```bash
npm run example:react
```

Or manually:

```bash
cd react-minimal
npm install
npm run dev
```

Run `npm run build` from the **repository root** first so `packages/*/dist` exists.

## Angular (`angular-minimal`)

Uses **`dynamic-tsparticles-angular`** via `file:../../packages/angular`.

From repo root:

```bash
npm run example:angular
```

Or manually (build the library first):

```bash
cd angular-minimal
npm install
npm start
```
