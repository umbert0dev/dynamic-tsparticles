# dynamic-tsparticles-vue3

Vue 3 adapter for tsParticles with a dynamic-speed mover and optional Web Audio. Peer deps only: Vue + `@tsparticles/vue3` + `tsparticles` + `@tsparticles/engine`.

Full docs: [dynamic-tsparticles (monorepo README)](https://github.com/umbert0dev/dynamic-tsparticles#readme).

```bash
npm install dynamic-tsparticles-vue3 vue @tsparticles/vue3 tsparticles @tsparticles/engine
```

```js
import { createDynamicParticlesState, DynamicParticles } from "dynamic-tsparticles-vue3";
```
